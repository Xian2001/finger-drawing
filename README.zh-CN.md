# Finger Drawing（画笔触控板）

把 Mac 触控板当成画笔：做一次手势 → 鼠标左键就一直处于按下状态，之后手指在触控板上滑动就能连续画线，**不用真的按住触控板**。再同一次手势 → 松开。

**English documentation: [README.md](README.md)** · **下载：[最新版本](https://github.com/Xian2001/finger-drawing/releases/latest)**

> 一个 mac 菜单栏小工具，没有窗口、不占 Dock，只在菜单栏放一个小铅笔。

---

## 功能

- **不按触控板也能画**：开启后单指滑动即连续笔迹，备忘录、预览标记、Sketch、Photoshop、截图标注等所有支持鼠标绘制的软件都能用。
- **触发手势可自定义**：

  | 手势 | 手指数 | 轻点次数 |
  | --- | --- | --- |
  | 单指双击（默认） | 1 | 2 |
  | 单指三击 | 1 | 3 |
  | 两指轻点 | 2 | 1 |
  | 三指轻点 | 3 | 1 |
  | 四指轻点 | 4 | 1 |

- **总开关**：菜单栏第一项。取消勾选后软件完全不生效——不识别手势、也不碰你的鼠标。
- **可选的全局键盘快捷键**：在手势子菜单里录一个组合键（⌘ / ⌥ / ⌃ / ⇧ + 任意键），之后在任何软件里都能用它开关画笔模式；注册这个快捷键不需要辅助功能权限。**触控板手势和键盘快捷键二选一**：设了快捷键，触控板手势自动停用；重新选一个手势，快捷键同时作废。
- **状态会记住**：总开关、触发手势、键盘快捷键都会持久化，下次启动沿用。
- **只允许一个实例**：如果又开了第二份（桌面副本、解压出来的下载副本等），它会立刻退出，不会出现多个图标抢同一个快捷键。
- **不会误触发**：只认「真轻点」——时长 < 0.3 秒、手指几乎不动、所需手指在 0.15 秒内一起落下。用力按下、按住、滑动都不会被当成手势。

### 键盘快捷键

点开 `触发手势` 子菜单里的 `键盘快捷键：未设置（点此设置）`，会弹出一个小窗口：在里面按下想要的组合键（必须至少含 ⌘ / ⌥ / ⌃ 之一），再点「保存」（或按回车）即生效。按 Esc 关闭则什么都不改，「清除快捷键」可以删掉已设置的快捷键。

快捷键走的是 Carbon 的 `RegisterEventHotKey`，所以另一个软件在前台时也能触发，按键会被它吃掉、不会漏给前台应用，而且不需要辅助功能权限。如果这个组合键已被系统或其他软件占用，会直接提示你并保留原来那个。

同一时间只有一个触发方式在生效：保存快捷键后，触控板手势就不再响应（避免误触）；点「清除快捷键」或在同一子菜单里重新选一个手势，就切回触控板、快捷键随之作废。菜单标题会直接显示当前生效的是哪一个：`触发方式：触控板手势（…）` 或 `触发方式：键盘快捷键 ⌃⌥P`。

```

    开启画笔模式 / 关闭画笔模式    ← 手动开关
    触发手势：单指双击（默认）      ← 手势子菜单
        ├ 单指双击 / 单指三击 / 两指 / 三指 / 四指轻点
        ├ ─────────────
        ├ 键盘快捷键：⌃⌥P（点此修改）
        └ 清除快捷键
  ─────────────────────
  重新连接触控板
  使用说明
  辅助功能权限：已就绪 / 未授权（点此授权）
  打开日志
  ─────────────────────
```

画笔模式开启时图标旁会出现「开」，总开关关闭时图标变灰。

## 系统要求

- macOS 12.0 及以上（在 macOS 26 / 27、Apple Silicon 上开发并实测）。
- 现成安装包为 **arm64**；Intel Mac 请按下方说明自行编译（`-target x86_64-apple-macos12.0`）。
- 需要 **辅助功能** 权限——它才允许软件替你一直按住鼠标左键。

## 安装

### 方式一：直接用现成的 App

1. 解压发布包，把 `Finger Drawing.app` 拖到「应用程序」文件夹（放哪都行，建议放这里）。
2. 第一次打开请 **右键 → 打开**（App 未经过公证）。
3. 系统会要求 **辅助功能** 权限：
   - 打开 **系统设置 → 隐私与安全性 → 辅助功能**，勾选 **Finger Drawing**（列表里没有就用左下角 `＋` 拖进去）；
   - 权限是在进程启动时读取的，勾选后重新打开一次 App 才会生效（可以点菜单里的「辅助功能权限 → 重新启动」）。

### 方式二：从源码编译

```bash
xcode-select --install                 # 只需一次，装 Swift 工具链
git clone https://github.com/Xian2001/finger-drawing.git
cd finger-drawing
bash build.sh                          # 生成「Finger Drawing.app」
```

`build.sh` 会用 `swiftc` 编译 `src/main.swift`、拷贝图标，并用钥匙串里第一个 `Apple Development` 证书签名（找不到就退回 ad-hoc 签名）。

## 常见问题

**系统设置里明明勾上了，菜单还显示「未授权」。**
说明数据库里那条权限记录和当前二进制的代码要求对不上（ad-hoc 签名、或重新签名后最常见）。把勾去掉再勾回来，或者：

```bash
tccutil reset Accessibility com.fingerdrawing.app
```

然后重开 App 重新授权。用真实签名证书（Apple Development 或自签名）签的话，重新编译也不会掉权限。

**菜单栏里看不到铅笔图标。**
macOS 26/27 会把新状态项排在应用菜单右侧，菜单栏排满时会被折进 `«` 折叠区。点一下 `«` 就能展开，也可以按住 ⌘ 拖动它到空位，系统会记住位置。

**三指/四指轻点同时触发了系统手势。**
到 **系统设置 → 触控板 → 更多手势** 里关掉冲突的那项（例如「查询与数据检测器」、调度中心）。

**切换软件后画不出线了。**
确认画笔模式还开着（图标旁有「开」），先在目标软件里点一下让它到前台，再继续画。

## 实现原理

- **手势识别**：读取 `MultitouchSupport.framework`（私有框架）的原始触摸帧（`MTDeviceCreateList` / `MTRegisterContactFrameCallback`）。只有 state `3`/`4`（真正接触）才算触摸，悬停状态忽略。本机实测触摸结构体步长 96 字节，`state` 在偏移 20，归一化坐标在偏移 32/36。
- **手势归并**：150ms 内落下的手指算同一组；整组里每根手指都在 300ms 内抬起、位移小于触控板宽度的 4.8%，才算一次有效轻点。550ms 内的连续有效轻点按「多击」累计。
- **替你按住鼠标**：在 `.cgSessionEventTap` 装 `CGEvent` 监听；开启后的第一次指针移动发合成 `leftMouseDown`（起笔），之后每次移动补 `leftMouseDragged`，关闭时发 `leftMouseUp`（收笔）。合成事件带 `eventSourceUserData` 标记，程序会跳过自己的事件，避免自激。
- 所有阈值集中在 `src/main.swift` 顶部的 `Tune`。

## 已知限制

- 用了**私有框架**，上不了 App Store，只适合自用和自签名分发。
- 未公证，首次打开需要右键 → 打开。
- 原始触摸结构依赖系统版本，未来 macOS 可能改动布局或接口。
- 手势判定是启发式的，没有灵敏度滑块；觉得太灵敏/太迟钝可以直接改 `Tune`。
